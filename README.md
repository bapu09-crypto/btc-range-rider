Range rider is a long-only BTC trading bot for the make.fun 24-hour live race. It buys when the close sits in the bottom 15% of the trailing 8-hour range and sells in the top 10%, with a 0.80% trailing stop, a 720-bar time stop, and a 30-bar cooldown after each sale. Python stdlib only; deterministic.

## Run it

```sh
python3 main.py
```
